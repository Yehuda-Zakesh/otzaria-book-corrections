# שדה החלפה בחיפוש בתוך ספר — פרומפט לאוצריא

בתוסף מומש תהליך שני שלבים דרך `searchFieldActions`. לבקשת המשתמש הכפתור נשאר במניפסט עם מינימום 0.9.98, אך מאמת ההתקנה של אוצריא חוסם שילוב זה ודורש מינימום 0.9.99. נדרשת התאמת סף האימות בבנייה הפרטית, שבה ה־API כבר קיים. אין צורך ב־API חדש עבור הכפתור והתהליך הקיימים.

להוספת שדה החלפה נפרד בתוך הקורא, העתיקו למאגר אוצריא:

> בבנייה הפרטית המסומנת 0.9.98, ה־API כבר קיים אך `_searchFieldActionsMinVersion` ב-`lib/plugins/services/plugin_extended_validator.dart` עדיין מוגדר 0.9.99. התאימו במפורש את סף האימות ל-0.9.98 בבנייה זו והוסיפו בדיקת התקנה מלאה עם המניפסט הקיים של התוסף, כולל `replace-in-book` והרשאת `search.field_actions`. אין צורך להוסיף API כדי להפעיל את התהליך הקיים בשני שלבים. אל תניחו שכל גרסת 0.9.98 כוללת את ה־API. השינוי הבא לשדה נפרד הוא בקשה נוספת ואינו תנאי להפעלת הכפתור הנוכחי.
>
> קרא את AGENTS.md ואת רכיבי העיצוב הקיימים לפני שינוי. הוסף לתיבת החיפוש בתוך ספר טקסט כפתור שמציג ומסתיר תיבת „החלפה ב־” נוספת, בלי לפתוח דף תוסף ובלי לשנות את הטקסט המקורי של החיפוש. השתמש ברכיבי השדות, הפוקוס והצבעים הקיימים באוצריא. מסלול התוסף נמצא ב-`C:\Users\Zeev Levental\Documents\Error reporting plugin\plugin\reader-replace.js` וב-`find-replace.js`.
>
> התחל מ-`lib/text_book/view/text_book_search_screen.dart`, `lib/plugins/view/plugin_search_field_actions.dart`, `lib/plugins/models/plugin_search_field_action.dart`, `lib/plugins/services/plugin_search_field_session_service.dart`, ומרישום `searchFieldActions` בהפעלה. ודא את הנתיבים ב-checkout הנוכחי. כיום תרומת השדה מציירת IconButton בלבד, ו-`search.setFieldText` מחליף את הבחירה/מוסיף במיקום הסמן; הוא אינו מאפשר לשנות את placeholder או להוסיף TextBox.
>
> העדף הרחבה מצומצמת ומוצהרת של פעולת החיפוש הקיימת, או פעולה מובנית בקורא, ולא API ליצירת ממשק שרירותי. התיבה הנוספת נשארת בבעלות המארח. בהפעלת תוסף יש למסור snapshot של החיפוש, החלופה, אפשרויות ההתאמה וזהות הספר/הלשונית. שמור תאימות למניפסטים ולאירועים קיימים והגדר זיהוי יכולת; התוסף יוכל להשאיר את חלופת שני השלבים בגרסאות שאין בהן שדה נוסף.
>
> חשוב: `search.fieldAction.invoked` הנוכחי מכיל text/selection/sessionId/field, אך לא bookUid או tabId. הוסף מטא-דאטה מאומתת מה-binding המקורי ברגע הלחיצה: bookUid, tabId וסשן תיקון אם ישנו. אסור להסיק את ספר המקור מהספר הפעיל לאחר lazy boot או מעבר חלונית. שמור בעלות לפי plugin/instance, ביטול וסיום עם סגירת השדה/הלשונית, ואל תאפשר לאירוע ישן לדרוס פעולה חדשה.
>
> חיפוש והחלפה צריכים להתבסס על הנוסח המתוקן הנוכחי, לכלול מילה או ביטוי, ולהבהיר אם נבחר חיפוש מדויק/מילים שלמות/ניקוד. החלפה ריקה היא מחיקה מפורשת. יש להציג כמות התאמות והפסקאות לפני החלה, לדרוש אישור, לשמר תיקונים ידניים אחרים ולבצע restore אטומי עם אימות raw source, טקסט קנוני, libraryVersion ו-expectedRevision. אין לשנות ספרייה או לשלוח דיווח אוטומטי. אין להשתמש ב-`state.content` של טווחים עצלים כראיה שהמקור ריק: `getSectionTextMap` עשוי להחזיר placeholder. קרא את מקור הפסקה מה-repository בעת האימות, כפי ששירות הסשנים כבר עושה.

# שליחת הצעות תיקון — גרסה 0.4.2

התוסף משתמש ב-SDK הקיים באוצריא 0.9.98. אין שימוש ב-API החדש.

1. לפני הכנת הדיווחים נקרא המייל מהגדרות אוצריא ומאומת שמקטעי המקור לא השתנו.
2. כל שינוי הופך לדיווח בפורמט הישן, עם המקור, הנוסח המוצע, הספר, הפסקה, ההקשר ופרטי המקור. שם הספר, המיקום ומספר השורה במקור נכללים גם בגוף `error_details`, כדי שיופיעו גם בהודעה שמציגה רק את תוכן הדיווח. כשאין `currentRef`, נשלח המיקום `פסקה N` לפי מספר הפסקה במקור (החל מ־1).
3. השליחה נעשית באמצעות `network.fetchStream` אל `https://otzaria.org/api/reportingerrors`, עם הרשאת `network.access` ורשימת היעדים המותרת במניפסט.
4. הצלחה דורשת HTTP 200 ותשובת JSON עם `success: true`. אם השרת מחזיר `email_sent: false` ללא `duplicate: true`, מוצג כשל במייל והתור נשמר לניסיון חוזר עם אותו מזהה. שרת ישן שאינו מחזיר את השדה ממשיך להיתמך. הדיווח הוא הצעה לבדיקה ידנית, ואינו משנה את הספר המקומי.
5. לאחר כשל, המטען והמזהה נשמרים בטיוטה המקומית לניסיון ידני נוסף. HTTP 409 מחליף את המזהה. שליחה חלקית ממשיכה רק בדיווחים שטרם נשלחו.
6. לכל לשונית יש טיוטה ותור משלה. כל הספרים והלשונית הפעילה נשמרים יחד במפתח `book-session`, בפורמט `schemaVersion: 2`. טיוטה בודדת מהגרסאות הקודמות נטענת כלשונית הראשונה.
7. אחרי כשל ללא דיווחים שאושרו ניתן להמשיך לערוך, גם אחרי פתיחה מחדש. ניסיון חוזר ללא עריכה שומר את המטען והמזהה המקוריים. שינוי בטקסט מבטל את התור הישן ויכין דיווחים חדשים מהנוסח המעודכן בלחיצה הבאה על שליחה. אחרי שליחה חלקית העריכה נשארת נעולה עד להשלמת התור.

התוסף **דורש חיבור לרשת**: במניפסט מוגדר `network.enabled: true`, שאוצריא מפרשת כ-`requiresNetwork`. ריצת הפרסום הרשמית מעבירה את הדרישה לחנות. אין שימוש בתור הדיווחים של אוצריא או שליחה אוטומטית כשהחיבור חוזר; התור המקומי דורש לחיצה להמשך השליחה.

כל עבודת ה-API העתידי, כולל המימוש האחרון ו-patch מעודכן לאוצריא, שמורה בענף `api/native-book-corrections`. היא אינה חלק מהגרסה הפעילה ב-main. לאחר קבלת ה-API יוחלף מסלול השליחה.

בדיקות הקוד והדפדפן משתמשות בשרת מדומה; הן אינן שולחות דיווחים אמיתיים.

# חיבור הדיווח המובנה — פעיל בגרסה 0.3.4

הגרסה הפעילה 0.3.4 שולחת דרך `feedback.submitBookCorrection` עם הרשאת `feedback.send_email` ו-`allowQueue: false`. אוצריא מאמתת את המקור הגולמי ובונה תיקון v2 כשהטווח חד־משמעי. התוסף מציג בנפרד את מספר התיקונים הישירים וההצעות לפי `correctionSupported` בתשובה.

מימוש ה-API, תיקוני אוצריא והחיבור המקורי נשמרו בענף GitHub `archive/native-reporting` (מבוסס על commit `2335b20`). ה-patch נמצא גם ב-`docs/otzaria-book-reporting.patch`, והשינויים בקוד אוצריא המקומי נשארו במקומם. אין להחיל את ה-patch שוב על אותו עותק שכבר עודכן.

החיבור הפעיל:

1. `minAppVersion` הוא 0.9.98 לבקשת המשתמש, עבור הקוד המקומי המעודכן שבו הממשק קיים. מאמת ה-SDK עדיין מסמן את הממשק כזמין מ-0.9.99 ועלול לדחות את התוסף בבדיקת התאימות המורחבת. גרסת 0.9.98 ללא הממשק אינה נתמכת בשליחה; קוד אוצריא לא שונה.
2. כל `item.request` נשלח עם `allowQueue: false`; כשל נשאר בטיוטה לניסיון ידני.
3. `forceFreeText: true` נשמר לחלקים של תיקון גדול. טווח עמום או חוצה פסקאות עשוי גם הוא להישלח כהצעה בלבד.
4. `error.report_id_conflict` מחדש את מזהה הפריט ושומר אותו לפני ניסיון נוסף.
5. בדיקות יחידה ודפדפן משתמשות בשליחה מדומה ומכסות ניסיון חוזר, שליחה חלקית, התנגשות מזהים ועריכה אחרי הצלחה. לא נשלח דיווח אמיתי לשרת.

אין מעבר אוטומטי למסלול v1. השליחה אינה משנה את הספר המקומי; אוצריא אחראית לאימות טווחי המקור ולמטא-דאטה של הדיווח.

# חיבור הדיווח המובנה — שמור להמשך

הגרסה הפעילה 0.3.1 שולחת ישירות ל-`https://otzaria.org/api/reportingerrors` דרך `network.fetchStream`, ותומכת באוצריא 0.9.98 הרגילה. אין בה קריאה ל-API הדיווח החדש ואין שמירה בתור הדיווחים המובנה.

מימוש ה-API, תיקוני אוצריא והחיבור המקורי נשמרו בענף GitHub `archive/native-reporting` (מבוסס על commit `2335b20`). ה-patch נמצא גם ב-`docs/otzaria-book-reporting.patch`, והשינויים בקוד אוצריא המקומי נשארו במקומם. אין להחיל את ה-patch שוב על אותו עותק שכבר עודכן.

כאשר הממשק יתקבל באוצריא ויפורסם:

1. לעדכן את `minAppVersion` לגרסה הרשמית שמכילה אותו.
2. להוסיף `ui.feedback` ולשלוח את `item.request` אל `feedback.submitBookCorrection` במקום `sendReport(host, item.payload)`.
3. להמשיך לקרוא את המייל מהגדרות התוכנה לפני השליחה. `allowQueue: false` משאיר את התור כבוי; שינויו דורש החלטה מפורשת של המשתמש.
4. להעביר `forceFreeText: true` לחלקים של תיקון גדול כדי למנוע הצעות מובנות מטעות; עבודה זו כבר נשמרת ב-`prepareReports`.
5. לטפל ב-`error.report_id_conflict` בחידוש מזהה ולשמור את התקדמות השליחה.
6. להחזיר את `reader-book` למניפסט רק כאשר גם הקשר זה נתמך בגרסה הרשמית.
7. להפעיל את בדיקות השליחה המובנית ואת בדיקת הדפדפן מהענף השמור ולבדוק תאימות מול SDK הרשמי.

החיבור המובנה בונה דיווח v2 עם אימות המקור הגולמי. המסלול הישיר משתמש כרגע בדיווח טקסט v1 עם מקור, הצעה ומיקום; אין ליצור טווחי DB מטקסט שהוסרו ממנו תגיות HTML.

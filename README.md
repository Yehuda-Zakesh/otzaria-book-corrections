# תיקוני ספרים לאוצריא

תוסף ניסיוני, גרסה 0.1.1, לאוצריא 0.9.98 ומעלה, הדורש חיבור לרשת. פותחים ספרים בלשוניות, מתקנים ולוחצים **שלח דיווח**. טווחים שאומתו מול המקור הגולמי נשלחים כהצעות תיקון מובנות בחוזה v2, באמצעות ה־SDK הקיים. שינויים שאינם ניתנים למיפוי בטוח נשלחים כהצעות טקסט לבדיקה ידנית עם מיקום ונוסח לפני/אחרי. השליחה אינה משנה את ספרי הספרייה המקומיים.

## מצב נוכחי

- מסך ספר מלא עם ניווט בצד ימין, עץ כותרות עם הרחבה וצמצום, חיפוש בכותרות וחיפוש בתוך הטקסט הערוך. הצבעים והגופנים מתקבלים מאוצריא; מידות וצורת השורות מותאמות לרכיבי הניווט שלה. רכיבי הניווט של התוסף כתובים ב-HTML/CSS ולא דורשים API ניווט חדש.
- ספר מועבר ממסך העיון באותו מיקום, לפי הפסקה והיסט הבחירה שה-SDK מספק. המיקומים ממופים מחדש לאחר עריכה, הוספה או מחיקה.
- תצוגת הניקוד נקראת ממדיניות התצוגה של אוצריא עבור הספר דרך ה-SDK, בפתיחה, בשחזור טיוטה ובחזרה לתוסף. הסתרת הניקוד אינה תיקון: המקור המנוקד נשמר בטיוטה ובדיווחים, ומיקומי בחירה, חיפוש וניווט מתורגמים בין התצוגה למקור. אם ה-SDK אינו מחזיר את נתוני המדיניות, מוצג המקור ללא הסתרה נוספת.
- מסך הבית הוא ספריית אוצריא: ניווט בקטגוריות וחיפוש לפי ספר או מחבר. התצוגה (רשת כרטיסים או רשימה עם עץ נפתח) עוקבת אוטומטית אחר הגדרת המשתמש באוצריא, גם אחרי שינוי ההגדרה וחזרה לתוסף. אין כפתורי החלפת תצוגה בתוסף או בחירה מתוך ספרים פתוחים. PDF אינו עורך טקסט.
- כפתור **+** בסרגל העליון (״פתח ספר נוסף״) פותח ספר בלשונית חדשה. מעבר בין הלשוניות משמר לכל ספר את הטקסט, תור השליחה, הגלילה, הבחירה, החיפוש ותוכן העניינים. ספר שכבר פתוח נבחר מחדש בלי לדרוס את הטיוטה. בסגירת לשונית עם תיקונים שלא נשלחו מוצג אישור מחיקה.
- בחירת ספר טקסט בספרייה טוענת אותו ללשונית תיקון גם כשאינו פתוח באוצריא; ספרים מסוגים אחרים נפתחים בקורא של אוצריא. כפתור **+** מחזיר לספרייה לבחירת ספר נוסף.
- כל הלשוניות נשמרות ומשוחזרות בטעינה מחדש. טיוטה מגרסה קודמת נטענת כלשונית ראשונה. חצי שמאל/ימין עוברים בין לשוניות ב-RTL; Home/End עוברים לראשונה/אחרונה.
- לאחר כשל בשליחה לפני אישור דיווח כלשהו אפשר להמשיך לערוך גם אחרי פתיחה מחדש. שינוי בנוסח מבטל את הדיווחים הישנים שלא נשלחו; ניסיון חוזר בלי עריכה שומר את המזהים. בשליחה חלקית העריכה נשארת נעולה עד להשלמת התור. עורך שנטען בלשונית מוסתרת מאותחל כשהיא נעשית גלויה.
- בעת נעילה בגלל שליחה חלקית מוצג הסבר קבוע עם מספר הדיווחים שנשלחו והנחיה לוודא חיבור לרשת וללחוץ על **המשך שליחה**. ההסבר משוחזר גם בפתיחה מחדש, ונעלם כשהשליחה מסתיימת והעריכה נפתחת.
- האייקון באוצריא הוא `document_edit_24_regular`, ללשונית התוסף ולפעולת העברת ספר לתיקון בלחיצה ימנית.
- כתובת המייל אינה מוצגת בתוסף. לפני שליחה נקראת הכתובת מהגדרות אוצריא; אם היא חסרה מופיעה ההודעה **יש לעדכן מייל לפני השליחה בהגדרות התוכנה**.
- טיוטת העריכה נשמרת. השליחה סדרתית, עם מזהים יציבים ושמירת התקדמות, כך שניסיון חוזר אינו שולח מחדש דיווחים שסומנו כנשלחו.
- אין שימוש בתור הדיווחים המובנה. כשל בשליחה שומר את הטיוטה והתקדמות השליחה לניסיון ידני בהמשך, ללא שליחה אוטומטית ברקע.
- לספר יש פס גלילה רציף אחד, שעוצר בתחילת הספר ובסופו. מאחורי הקלעים נפרסת רק סביבת הקריאה (עד שלושה מקטעים של 16,001 תווים), כדי לשמור על ביצועים בספרים גדולים. אין סרגל אחוזים או כפתורי מעבר בין מקטעים. הניווט בצד עוקב אחר המיקום הגלוי, פותח את מסלול הכותרת ומביא את השורה הפעילה לתצוגה. החיפוש והטיוטה כוללים את הספר המלא; בחירה והעתקה בשדה העריכה כוללות את חלון הטקסט המוצג.
- אחרי שליחה מוצלחת אפשר להמשיך לתקן באותו ספר. תיקונים זהים שכבר דווחו אינם נשלחים שוב.

## שליחה ישירה ותאימות

השליחה משתמשת ב-`network.fetchStream` עם הרשאת `network.access`, בבקשת POST אל `https://otzaria.org/api/reportingerrors`. דיווח מובנה כולל `schema_version: 2`,‏ `report_kind: text_correction`, מקור גולמי, טווח UTF-16, נוסח מוצע, מיקום ו־digest התואם לאוצריא. הוספה נשלחת כהחלפת שורה שלמה ששומרת את סביבתה; שינוי בפסקאות אחדות מפוצל כשגבולותיהן נשמרים. מיפוי HTML וישויות נבדק מול טקסט המקור, ושינוי שחוצה תגיות או משנה גבולות פסקאות נשאר דיווח חופשי עם הסבר. גרסת בניית הספרייה ו־heRef אינם נחשפים בממשק הזה ולכן אינם מומצאים.

הצלחה מסומנת רק לאחר HTTP 200 ותשובת JSON עם `success: true`, ללא כשל מפורש במייל. הודעת הסיום מבדילה בין הצעות מובנות שאושרו ב־`correction_supported: true`, הצעות חופשיות והצעות שהאתר לא אישר את סיווגן. אין תלות ב־API של 0.9.99 או שימוש בהרשאת `feedback.send_email`.

פותחים ספר לתיקון מתוך ספריית התוסף, או בלחיצה ימנית על טקסט מסומן בספר עצמו ובחירת **העבר את הספר לתיקון**.

## תאימות ושליחה

נדרשת אוצריא 0.9.98 ומעלה. השליחה מבוססת על ה-SDK הקיים, ללא קריאות ל-`feedback.submitBookCorrection`. [פרטי השליחה ודרישת הרשת](docs/legacy-reporting.md).

הטיוטות ותורי הדיווחים נשמרים מקומית, בנפרד לכל ספר. דיווחים שנשלחו אינם נשלחים שוב; כשל נשמר לניסיון ידני. אין תור של אוצריא או שליחה אוטומטית כשהחיבור חוזר. תורים שהוכנו לפני העדכון ממשיכים להישלח בפורמטם המקורי עם אותם מזהים. החיבור הקודם ל־API של 0.9.99 שמור בענף [api/native-book-corrections](https://github.com/Yehuda-Zakesh/otzaria-book-corrections/tree/api/native-book-corrections).

## התקנה ופיתוח חי

נדרש Node.js 22 ומעלה; אין תלויות npm.

`npm run dev` עוקב אחר קובצי המקור ובונה אוטומטית את `plugin/app.bundle.js`. באוצריא טוענים את תיקיית `plugin` כתוסף פיתוח. שינויי HTML/CSS נקלטים ישירות; אין לערוך את ה-bundle שנוצר. שינוי בקוד Dart של אוצריא דורש גם Flutter reload/restart ואינו חלק מטעינת התוסף החיה.

`npm run pack` בונה `dist/book-corrections-0.1.1.otzplugin`. `npm run qa` בודק תחביר, עקביות גרסאות ו-bundle, מריץ את בדיקות הקוד והדפדפן ואורז. `npm run test:browser` מפעיל Chrome או Edge במצב headless ובפורט זמני, עם SDK ושליחה מדומים; אפשר להגדיר `CHROME_PATH`. הריצה כוללת לשוניות, שחזור טיוטות, מקלדת, בחירה, חיפוש, גלילה בספר גדול וגבולות הספר. `npm run test:browser:attached` משתמש בדפדפן פתוח בפורט 9227 או `CDP_PORT`.

הטעינה תומכת בספרים עד 10MB. בקשות מיפוי ואחסון נשלחות במרווח 20ms עם ניסיון חוזר מוגבל לחסימת קצב. תגיות HTML מוסרות לפי כללי אוצריא, ולכן העורך משנה טקסט ולא עיצוב ספרים.

המקור נשמר בנפרד לכל ספר, והטיוטה שומרת רק את התיקונים ואת מצב העבודה. שמירה כושלת אינה מחליפה את העותק האחרון שנשמר בהצלחה; טיוטות מהפורמט הישן מועברות אוטומטית בשמירה מוצלחת. בקשות אחסון מקבלות עדיפות ומקום שמור בזמן קריאות ספרייה אטיות.

החיפוש שומר מטמון עבור הטקסט הנוכחי ומתבצע ב-Worker בספרים גדולים, עם חזרה שקטה לחיפוש רגיל אם Worker אינו זמין. בשחזור נבדק המקור ברקע ללא הודעה; לפני שליחה, כולל המשך של תור קיים, נבדקים שוב המקור והפסקאות הרלוונטיות. שינוי במקור עוצר את השליחה ושומר את הטיוטה. לא נוספו חלונות או כפתורים לתהליכים האלה.

הריפו: [Yehuda-Zakesh/otzaria-book-corrections](https://github.com/Yehuda-Zakesh/otzaria-book-corrections). העותק `upstream-otzaria`, חבילות פלט, לוגים, פרופילי דפדפן ותצלומי מסך אינם נכללים בריפו.

## CI ופרסום ב-GitHub

- **Package plugin**: ריצה נפרדת לאריזה בלבד, בכל push ל-main, PR אליו או ידנית. בודקת ואורזת את התוסף להורדה כ-artifact בשם `book-corrections` למשך 14 יום. אינה יוצרת Release, אינה משתמשת בסודות ואינה פונה לחנות אוצריא.
- **CI**: בכל push ל-main, PR אליו או הפעלה ידנית. בדיקות ב-Windows וב-Linux עם Node 22 ו-24, QA בדפדפן, אימות רשמי של אוצריא מול גרסה 0.9.98 ואריזה. קובץ ההתקנה ותצלומי הבדיקה נשמרים כ-artifacts למשך 14 יום.
- **Publish GitHub release**: ידנית דרך Actions או בדחיפת תג `v0.1.1` התואם לגרסת המניפסט. רצה קודם כל חבילת ה-CI, ורק לאחר הצלחה מתפרסם אותו artifact כ-Release. תג שאינו תואם לגרסה נדחה; Release קיים אינו נדרס.
- **Publish to Otzaria**: ידנית דרך Actions, מענף main בלבד. מריצה CI ומשתמשת באותו קובץ שנבדק. יש להגדיר `OTZARIA_USER` ו-`OTZARIA_PASSWORD` ב-[Repository secrets](https://github.com/Yehuda-Zakesh/otzaria-book-corrections/settings/secrets/actions). בפרסום ראשון מצורף `screenshots/main.png`, ויש לסמן הסכמה לקבלת דיווחי משתמשים. פרסום ראשון ממתין לאישור מנהל החנות.

פרסום אינו מופעל אוטומטית בדחיפה ל-main. ריצות PR ו-CI אינן מקבלות סודות חנות ואינן מפרסמות. ה-Actions מוצמדים ל-commit מאומת. [מקור כלי האימות והפרסום הרשמי](https://github.com/Otzaria/otzaria-plugin-validator).

לא נשלחו דיווחי בדיקה אמיתיים. בדיקות רשת משתמשות בהדמיה; יש לבדוק שליחה אמיתית רק עם תיקון שרוצים לדווח עליו.

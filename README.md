# תיקוני ספרים לאוצריא

תוסף ניסיוני, גרסה 0.3.1, לאוצריא 0.9.98 הרגילה. טוענים עותק של ספר טקסט לעורך התוסף, מתקנים כרצונכם ולוחצים **שלח דיווח**. התוסף משווה למקור ושולח את השינויים ישירות לשירות דיווחי השגיאות. אין תלות ב-API הדיווח החדש ואין כתיבה לספרי הספרייה.

## מצב נוכחי

- מסך ספר מלא עם ניווט בצד ימין, עץ כותרות עם הרחבה וצמצום, חיפוש בכותרות וחיפוש בתוך הטקסט הערוך. הצבעים והגופנים מתקבלים מאוצריא; מידות וצורת השורות מותאמות לרכיבי הניווט שלה. רכיבי הניווט של התוסף כתובים ב-HTML/CSS ולא דורשים API ניווט חדש.
- ספר מועבר ממסך העיון באותו מיקום, לפי הפסקה והיסט הבחירה שה-SDK מספק. המיקומים ממופים מחדש לאחר עריכה, הוספה או מחיקה.
- כפתור טעינת הספר ממורכז. כשכמה ספרי טקסט פתוחים, בוחרים איזה מהם לייבא. PDF אינו עורך טקסט.
- כפתור **החלף ספר** בסרגל פותח בחירה מחדש של הספרים הפתוחים. הטקסט, הכותרת ותוכן העניינים מתחלפים יחד. אפשר לחזור לספר שבעריכה בלי למחוק את הטיוטה; מעבר עם תיקונים שלא נשלחו דורש פעולת ביטול מפורשת.
- כתובת המייל אינה מוצגת בתוסף. לפני שליחה נקראת הכתובת מהגדרות אוצריא; אם היא חסרה מופיעה ההודעה **יש לעדכן מייל לפני השליחה בהגדרות התוכנה**.
- טיוטת העריכה נשמרת. השליחה סדרתית, עם מזהים יציבים ושמירת התקדמות, כך שניסיון חוזר אינו שולח מחדש דיווחים שסומנו כנשלחו.
- אין שימוש בתור הדיווחים המובנה. כשל בשליחה שומר את הטיוטה והתקדמות השליחה לניסיון ידני בהמשך, ללא שליחה אוטומטית ברקע.

## שליחה ישירה ותאימות

השליחה הפעילה משתמשת ב-`network.fetchStream` שכבר קיים באוצריא 0.9.98, אל `https://otzaria.org/api/reportingerrors`. יש לאשר את הרשאת הרשת של התוסף. הדיווח נשלח בפורמט הטקסט הקיים, עם מקור, נוסח מוצע, מיקום והקשר.

באוצריא הרגילה פותחים את הספר לתיקון מהכפתור בסרגל הספר, או בלחיצה ימנית על טקסט מסומן. הלחיצה הימנית בלי סימון דורשת את שינוי אוצריא המתואר להלן ואינה מוצהרת במניפסט של גרסה 0.3.1.

## עבודת ה-API נשמרה להמשך

החיבור המקורי נשמר בענף GitHub `archive/native-reporting`, והקוד המקומי באוצריא נשאר במקומו. [הוראות החזרת החיבור כאשר יתקבל רשמית](docs/native-reporting-integration.md). הגרסה הפעילה אינה מפעילה אותו. העבודה כוללת:

1. `feedback.submitBookCorrection` — אימות המקור הרשמי ושליחת דיווח v2 דרך `DirectErrorReportService`, עם המייל והמטא-דאטה של אוצריא. ה-API אינו משנה את תוכן הספרים.
2. הקשר `reader-book` — הצגת **העבר את הספר לתיקון** בלחיצה ימנית גם בלי סימון. זהות הספר והפסקה נלכדות בזמן הלחיצה.

השינויים יושמו ב-`C:\Users\Zeev Levental\Documents\otzaria`. [קובץ patch לעיון או להעברה למפתחים](docs/otzaria-book-reporting.patch) כולל את שינויי הדיווח והתפריט, בלי השינויים המקומיים האחרים של המשתמש.

החיבור העתידי בונה תיקון v2 מובנה רק אם הטווח תואם למקור הגולמי. כשיש עמימות בגלל תגיות HTML, שינוי חוצה פסקאות או חלקים של תיקון גדול, הוא משתמש בטקסט חופשי. עד לקבלת ה-API נשלח דיווח טקסט v1, ללא יצירת היסטי DB משוערים.

## התקנה ופיתוח חי

נדרש Node.js 22 ומעלה; אין תלויות npm.

`npm run dev` עוקב אחר קובצי המקור ובונה אוטומטית את `plugin/app.bundle.js`. באוצריא טוענים את תיקיית `plugin` כתוסף פיתוח. שינויי HTML/CSS נקלטים ישירות; אין לערוך את ה-bundle שנוצר. שינוי בקוד Dart של אוצריא דורש גם Flutter reload/restart ואינו חלק מטעינת התוסף החיה.

`npm run pack` בונה `dist/book-corrections-0.3.1.otzplugin` להתקנה. `npm test` מריץ בדיקות טעינה, בחירת ספר, השוואה, ניווט, חיפוש, חסימת קצב בקשות ומחזור שליחה. `npm run test:browser` מיועד ל-Chrome עם SDK ורשת מדומים, דרך CDP בפורט 9227.

הטעינה תומכת בספרים עד 10MB. בקשות מיפוי ואחסון נשלחות במרווח 20ms עם ניסיון חוזר מוגבל לחסימת קצב. תגיות HTML מוסרות לפי כללי אוצריא, ולכן העורך משנה טקסט ולא עיצוב ספרים.

הריפו: [Yehuda-Zakesh/otzaria-book-corrections](https://github.com/Yehuda-Zakesh/otzaria-book-corrections). העותק `upstream-otzaria`, חבילות פלט, לוגים, פרופילי דפדפן ותצלומי מסך אינם נכללים בריפו.

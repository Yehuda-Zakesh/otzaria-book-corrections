# תיקוני ספרים לאוצריא

תוסף ניסיוני, גרסה 0.3.0, לאוצריא 0.9.99 ומעלה (חוזה הסשנים והטיוטות של [Otzaria PR #2311](https://github.com/Otzaria/otzaria/pull/2311)). הנוסח נערך בקורא של אוצריא עצמה, עם הבאנר וסימון הפסקאות המתוקנות שלה. התוסף שומר את התיקונים, מציג התנגשויות להחלטה ושולח דיווחים דרך `feedback.submitBookCorrection`. הספר, קובץ המקור ומסד הספרייה אינם משתנים.

גרסה 0.3.0 אינה תואמת לאוצריא 0.9.98. הקוד הקודם של [גרסה 0.2.2](https://github.com/Yehuda-Zakesh/otzaria-book-corrections/tree/7c55bbd9c832e4aca4ee9eec43975bf25e82b576), התואמת ל־0.9.98, נשאר זמין בהיסטוריית המאגר.

## שימוש

- בספר טקסט: לחיצה ימנית (גם בלי סימון) ← **תיקון הספר בקורא**. הלחיצה נושאת את מזהה הלשונית המדויק, גם כשהספר פתוח בכמה לשוניות. אפשר גם לבחור לשונית ברשימה שבדף התוסף.
- כפתור הסרגל **תיקון הספר בקורא** אינו נושא מזהה לשונית (פער במארח). הוא פועל רק כשיש לשונית אחת של אותו ספר; אחרת מוצגת בקשה לבחור.
- העריכה, השמירה העמידה ו**סיום עריכה** נעשים בקורא של אוצריא. בדף התוסף: **שמירה ושליחה**, **סיום עריכה**, תיקונים ממתינים, התנגשויות והיסטוריה.
- שליחה מבקשת תיקון מובנה (`requireTextCorrection: true`). כשאי אפשר למפות אותו במדויק, המשתמש מחליט אם לשלוח דיווח חופשי. ההודעה מסבירה שדיווח חופשי מגיע לדוא״ל ואינו נכנס לתור התיקונים באתר.
- סטטוס `queued` מוצג כ„בתור הדיווחים של אוצריא — טרם נשלח לאתר”. `sent` עם `correctionSupported: true` מוצג כ„השליחה דרך אוצריא הושלמה — סטטוס הטיפול באתר אינו ידוע”: האתר מחזיר אישור זה גם לדיווחים שהוא מנתב לדוא״ל בלבד, ולכן אין בו הוכחה לכניסה לתור התיקונים, לאישור או לפרסום.
- טיוטות 0.2.2 מוצגות לקריאה בלבד. תיקון שנשאר בתוך פסקה אחת ושהמקור שלו לא השתנה אפשר להעביר לקורא; כל השאר נשאר להחלטת המשתמש.

חוזה השמירה, האישור והמיגרציה: [docs/correction-sessions.md](docs/correction-sessions.md).

## פיתוח ובדיקות

נדרש Node.js 22 ומעלה; אין תלויות npm. `npm run dev` בונה את `plugin/app.bundle.js` בכל שינוי. טוענים את `plugin/` כתוסף פיתוח באוצריא שנבנתה מהענף של PR #2311.

`npm run qa` מריץ check (תחביר, bundle ומדיניות התאימות של 0.9.99), בדיקות Node, בדיקת דפדפן ואריזה ל־`dist/book-corrections-0.3.0.otzplugin`. בדיקות Node והדפדפן משתמשות במודל של חוזה המארח (`test/fake-otzaria.mjs`); זו **אינה** בדיקת אינטגרציה מול אוצריא. עד מיזוג חוזה ה־SDK, האימות הרשמי ב־CI מוצמד למפרט של PR #2311 ב־`858a0cd78`, ולא למפרט `dev` שעדיין אינו מכיל אותו. הבדיקות החיות והמגבלות מתועדות ב־[docs/QA.md](docs/QA.md).

הריפו: [Yehuda-Zakesh/otzaria-book-corrections](https://github.com/Yehuda-Zakesh/otzaria-book-corrections).

## CI ופרסום ב-GitHub

- **Package plugin**: ריצה נפרדת לאריזה בלבד, בכל push ל-main, PR אליו או ידנית. בודקת ואורזת את התוסף להורדה כ-artifact בשם `book-corrections` למשך 14 יום. אינה יוצרת Release, אינה משתמשת בסודות ואינה פונה לחנות אוצריא.
- **CI**: בכל push ל-main, PR אליו או הפעלה ידנית. בדיקות ב-Windows וב-Linux עם Node 22 ו-24, QA בדפדפן, אימות רשמי של אוצריא מול גרסה 0.9.99 ואריזה. קובץ ההתקנה ותצלומי הבדיקה נשמרים כ-artifacts למשך 14 יום.
- **Publish GitHub release**: ידנית דרך Actions או בדחיפת תג `v<version>` התואם לגרסת המניפסט. רצה קודם כל חבילת ה-CI, ורק לאחר הצלחה מתפרסם אותו artifact כ-Release. תג שאינו תואם לגרסה נדחה; Release קיים אינו נדרס.
- **Publish to Otzaria**: ידנית דרך Actions, מענף main בלבד. מריצה CI ומשתמשת באותו קובץ שנבדק. יש להגדיר `OTZARIA_USER` ו-`OTZARIA_PASSWORD` ב-[Repository secrets](https://github.com/Yehuda-Zakesh/otzaria-book-corrections/settings/secrets/actions). בפרסום ראשון מצורף `screenshots/main.png`, ויש לסמן הסכמה לקבלת דיווחי משתמשים. פרסום ראשון ממתין לאישור מנהל החנות.

פרסום אינו מופעל אוטומטית בדחיפה ל-main. ריצות PR ו-CI אינן מקבלות סודות חנות ואינן מפרסמות. ה-Actions מוצמדים ל-commit מאומת. [מקור כלי האימות והפרסום הרשמי](https://github.com/Otzaria/otzaria-plugin-validator).

בדיקות הרשת האוטומטיות משתמשות בהדמיה. בבדיקה ידנית בוצע ניסיון לשלוח הצעות לאוצריא; בהיסטוריית התוסף הוצג אישור לתיקון מובנה. למגיש אין גישה לאתר התיקונים, ולכן הופעת ההצעות באתר וקליטתן בפועל לא אומתו עצמאית. אין לבצע שליחות בדיקה נוספות ללא בקשה מפורשת.
